# 柳本幸子 公式サイト

ソプラノ歌手・柳本幸子のサイト。日記と、公演(リサイタル・コンサート・イベント)とチラシの一覧。

## 構成

| ページ | ファイル | 用途 |
| --- | --- | --- |
| トップ | `index.html` | プロフィール・今後の公演・最新の日記 |
| 日記 | `diary.html` / `post.html?id=…` | 日記の一覧と個別記事 |
| 公演・チラシ | `concerts.html` | チラシ画像の一覧(今後/過去、種類・年で絞り込み) |
| 本人用 | `admin/` | 日記・公演・プロフィールの編集 |

- 内容はすべて `data/*.json` に入っています(`posts.json` 日記 / `events.json` 公演 / `profile.json` プロフィール)
- 画像は `images/posts/`(日記の写真)、`images/flyers/`(チラシ)、`images/profile/` に保存されます
- 閲覧用ページはただの静的ファイルなので、そのまま GitHub Pages に置けます

## 編集のしかた(本人用)

1. `起動.bat` をダブルクリック(Python が必要)
2. ブラウザで本人用ページ(http://localhost:8000/admin/)が開きます
3. 書いて「保存する」を押すと `data/` と `images/` に保存されます
4. 閲覧用ページは http://localhost:8000/ で確認できます

編集用サーバー(`server.py`)はこのPCの中(127.0.0.1)だけで動き、外からはアクセスできません。

## GitHub への公開とスマホからの編集

手順は [公開とスマホ設定の手順.md](公開とスマホ設定の手順.md) にまとめてあります。

`admin/store.js` が保存先を切り替えます。

- localhost で開いたとき: `server.py` に保存
- GitHub Pages で開いたとき: GitHub API(Contents API)でリポジトリに直接コミット。この場合は、その端末に保存したリポジトリ限定のアクセストークンを使います

公開後は、公開版の本人用ページから編集してください(ローカルで編集してアップロードすると、スマホで書いた内容を上書きしてしまいます)。
